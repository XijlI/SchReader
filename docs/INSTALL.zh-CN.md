# 安装与使用说明（给不用写代码的人）

SchReader 是一个 Chrome 扩展：把论文网页换成 Nature 系期刊那种版面。
**不用注册、不用联网下载、不保存任何东西。**
（多设备同步是可选的，需要一串免费的 GitHub token —— 见第六节。）

---

## 一、装一次（大约 30 秒）

1. 打开 Chrome，在地址栏输入下面这行，回车：

   ```
   chrome://extensions
   ```

   > 用 Edge 的话输入 `edge://extensions`

2. 看页面**右上角**，把 **“开发者模式 / Developer mode”** 的开关打开。
   打开后页面顶部会多出一排按钮。

3. 点左上角出现的 **“加载已解压的扩展程序 / Load unpacked”**，
   在弹出的选择框里找到本项目的 **`extension`** 文件夹，选中它，点“选择文件夹”。

   > 路径是本文件的上一级（本文件在 `docs/` 里）的 `extension` 文件夹，里面直接有 `manifest.json`。
   > 选的是文件夹本身，不是里面的文件。

4. 装好了。同页面上会出现一张叫 **SchReader — 论文重排阅读器** 的卡片。
   点浏览器右上角的拼图图标，把 SchReader 后面的**图钉**点亮，图标就会常驻在工具栏。

**如果第 3 步选错文件夹**：删掉卡片重来一次就行（卡片右下角有“移除”）。
报错信息里如果出现 "manifest" 字样，基本就是选到了上层目录。

> **想省事 / 换台电脑装**：每个版本都会在
> [Releases 页面](https://github.com/XijlI/SchReader/releases/latest) 放出
> `schreader-chrome-vX.Y.Z.zip`。下载解压到任意位置，第 3 步改成选**解压出来的那个文件夹**即可，
> 其余步骤完全一样。

## 二、怎么用

1. 正常打开一篇论文（ScienceDirect、Wiley、ACS、Springer、PLOS……都行），等正文显示出来。
2. 页面**右下角**会出现一个深色小胶囊：

   ```
   [S  SchReader  ▾]
   ```

   点它 → **新标签页**打开重排后的阅读版式。原页面不动，随时切回去对照。

3. 找不到胶囊？两个办法：
   - 点工具栏上的 **SchReader 图标**（效果一样）
   - 有些页面正文还没加载完，等一两秒或往下滚一点
   - 如果这个站点不在名单里，就不会出现胶囊 —— 见第三节
   - 工具栏上的 **SchReader 图标** 不会转换页面，它打开的是「我的文库」

4. 想以后这个站点自动转换：点胶囊右边的 **▾** → 勾上
   **This site: convert automatically**。

> Nature 官网（nature.com）不显示胶囊，因为它本来就是这个版式。

## 三、它会在哪些站点运行

SchReader 只在自己认识的出版社站点上运行 —— ScienceDirect、Wiley、Springer、Cell、PNAS、PLOS、
Frontiers、MDPI 等几十个。其他网站一概不碰，所以你看别的东西时它完全看不见。

- **遇到名单里没有的论文站**（不出现胶囊）：在任意别的论文页点胶囊旁的 **▾** → **allowed sites…**。
  设置面板会带着这个域名打开，点 **Allow site**，Chrome 询问权限时同意，然后刷新页面，胶囊就出来了。
- **查看 / 修改名单**：工具栏图标打开「我的文库」，点右上角 **⚙** → **Allowed sites**
  （内置出版社是一排小标签，你自己加的站点在下面，每条带 Remove 按钮）。
  `chrome://extensions` → SchReader → **详情** → **扩展程序选项** 打开的也是这个面板。
- 加进去就是一个普通的 Chrome 权限，随时可以同样地收回；移除之后扩展就完全读不到那个站。

## 四、阅读页怎么用

右侧栏三个标签页，就是你喜欢的那套导航：

- **Sections** —— 章节列表，滚动时自动高亮当前章节，点一下跳过去
- **Figures** —— 图片缩略图，点一下跳到正文里的那张图
- **Refs** —— 全部参考文献，点某条可以固定查看

顶栏中间显示的是**文章标题**（太长会省略，鼠标悬停能看全），标题下面一行是期刊名和域名。

正文里的上标数字（比如 `12`）：

- **鼠标悬停** → 浮出这条文献的完整信息 + DOI 链接
- **点一下** → 右侧切到 Refs 并高亮这一条，**正文不滚动**，你读到哪儿还停在哪儿

参考文献条目下面的 **↑ cited 3×** → 点它跳回正文里引用它的地方，并闪一下。

其他：

| 想做什么 | 怎么做 |
|---|---|
| 看图 / 缩放 | 点图片本身，或图上的 Expand；滚轮缩放（**25%–600%**，100% 是整幅正好放进窗口）；放大了按住拖动平移；← → 换图、Esc 关闭 |
| 换主题 / 字体 / 字号 | 顶栏 **Aa**，里面什么都调（也能自己挑背景色和文字色） |
| 划词高亮 | 选中文字 → 点右上角那支**笔**；默认黄色 |
| 换个高亮颜色 | **右键**点那支笔，选颜色（黄 / 绿 / 蓝 / 粉 / 紫 / 橙） |
| 改已有高亮 | **右键**点高亮处 → 换色，或按 ✕ 删掉 |
| 下一节 / 上一节 | `J` / `K` |
| 收起侧栏 | `Z`，或顶栏 **☰**（窄窗口下侧栏会变成抽屉） |
| 看解析情况 | 顶栏 **⋯**，会显示抓到了多少段落、多少图、多少条文献、多少条高亮 |

## 五、以后改了代码怎么更新

回到 `chrome://extensions`，在 SchReader 卡片上点 **↻**（刷新）按钮，
然后刷新论文页面重新点胶囊即可。不用卸载重装。

## 六、多设备同步（电脑 + 手机）

库、阅读位置、高亮可以在浏览器和手机之间保持一致。传的是一份很小的 JSON，放在你自己的
**私有 GitHub gist** 里：题名、链接、标签、备注、阅读位置 —— 正文永远不上传。

**每台设备各设置一次：**

1. 登录 GitHub，打开 <https://github.com/settings/tokens/new?scopes=gist&description=SchReader%20sync>。
2. 只勾 **gist** 这一项，划到下面点 **Generate token**。
3. 复制那串 token（只显示一次，`ghp_` 或 `github_pat_` 开头）。
4. 打开 SchReader 的 **⚙ 设置 → Sync**，粘进输入框，点 **Connect**。
5. 手机（以及别的电脑）重复 1–4，用**同一个** token —— 第二台设备会自己找到同一个 gist，
   不用手抄任何 id。

之后：每次改动静几秒就自动推上去，打开库时自动拉下来。两台设备改的是不同内容就都保留；
一台删掉的论文另一台也会消失。token 只存在那台设备本地，点 **Disconnect** 只是这台设备停止同步，
gist 和其他设备都不受影响。

出问题时 Sync 那一行会直接写出原因（"GitHub rejected the token (401)…"、"Network error…"），
不会悄悄失败 —— 把那句话发给我就行。

## 七、某个网站不好使怎么办

先在阅读页点顶栏 **⋯** 看诊断：

- **references 是 0** → 这个站的参考文献不是我认识的写法
- **figures 是 0** → 图片可能是懒加载，先在页面上往下滚到底再点胶囊
- **sections 是 0** → 正文可能藏在 PDF 或阅读器里，只能拿到摘要

把这两样发给我，我加一条适配器就行：**① 那个页面的网址；② 诊断面板的截图**。

---

## 八、卸载

`chrome://extensions` → SchReader 卡片 → **移除**。
不会在你电脑上留任何东西。
