SchReader 把任意出版社的论文页面，重新排成 Nature 系期刊那种阅读版式——正文一栏，右侧固定
**Sections / Figures / References** 三栏。同一套解析器和同一个阅读页，做成 Chrome 扩展和安卓 App
两个壳，两者只在"怎么拿到页面 HTML"这一步不同。

## 下载

| 文件 | 是什么 |
|---|---|
| `schreader-android-v0.1.0.apk` | 安卓 App，Android 8.0+（minSdk 26）。传到手机点开安装。 |
| `schreader-chrome-v0.1.0.zip` | Chrome / Edge 扩展（Manifest V3）。解压后打开 `chrome://extensions`，开开发者模式，点「加载已解压的扩展程序」，选中解压出来的文件夹。 |
| `SHA256SUMS.txt` | 上面两个文件的 SHA-256 校验值。 |

## 这一版有什么

**阅读页**
- 正文一栏 + 右侧分区/图表/文献固定栏；鼠标悬停角标引用即看原文，不用跳走。
- 图片灯箱；快捷键 `j`/`k`、`s`/`f`/`r`、`z`、`t`、`Esc`；每篇文章的排版可以单独调。
- 17 套阅读主题，外加一个"自定义配色"混色器：只给两个颜色，其余色阶自动推出来。

**文库**
- 只存元数据——题名、作者、期刊、年份、DOI、链接、你打的标签和备注、阅读位置。不存正文、不存
  PDF，所以阅读页仍然跑在你自己的登录会话里。
- 可搜索、打标签、写备注，有阅读历史；可导出/导入 BibTeX、RIS、CSV、JSON。

**搜索书架**
- Google Scholar 加一排期刊官网，也可以自己加；手机上加的站点和浏览器里的是同一份。

**浏览器扩展**
- 工具栏图标打开文库；在论文页右下角点悬浮胶囊，就把当前标签页变成阅读视图。
- 设置面板：主题、字体、字号，以及允许扩展运行的站点。

**安卓 App**
- 打开就是**我的文库**，底部三标签：文库 / 搜索 / 设置，和页面用同一套配色。
- 浏览器多标签（最多 8 个，重开自动恢复）；从某个分区点开的网页，再点该分区会回到你离开的页面
  ——停在阅读页就回到阅读页，滚动位置也保留。
- 页面缩放 25%–200%，系统分享，支持 `schreader://` 深链。

## 需要注意

- 包名是 `com.schreader.app`，会和改名前的旧包并存（旧包可以卸载）。
- 文库是空的：存储键跟着项目一起改了名，旧条目不会被读到。
- 正文每次都是现解析的，不归档；PDF 不渲染。
