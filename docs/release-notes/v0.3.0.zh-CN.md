## 0.3.0 新增

### 划词翻译

在阅读视图里选中一句话，荧光笔旁边会冒出一个金色「译」按钮，点它——或者直接按一下 **Y**，
译文就浮在文字旁边。

- 卡片只显示译文。**Copy** 复制到剪贴板；**Save note** 把「原文 + 译文」存进这篇文献的笔记
  （没收藏过的文献会先自动收藏，否则笔记没有地方挂）。
- 滚动时卡片跟着文字走；宽度按内容来：一个词就是 177 px 的小卡片，整段最多 384 px。深浅主题都跟
  你的阅读皮肤一致。
- **设置 → Translation**：可以关掉，也可以选目标语言（简体中文、繁體中文、English、日本語、
  한국어）。已经打开的文章不用刷新就跟着变。
- 长选区会按 1200 字符切段翻译再拼回去——实测跨四段的 2974 字符串，2.5 秒出结果。
- 走的是谷歌公开翻译接口：不用注册、不用填 key，什么都不用配。需要能上网（走代理才能访问的话，
  代理开着就行）。
- 只作用于阅读视图，出版社原页面不动。

### 不再拆词换行

正文行尾不再自动断词加连字符。之前 `hyphens: auto` 会把英文单词从中间断开：一段 20 行的摘要被压成
19 行，其中一个词被劈开。现在只在整词处换行，两端对齐保留；很长的 DOI / 链接仍然会断开，免得在手机上
把页面撑宽。

### 内部

- 新增 `extension/translate.js`（阅读页 + `android/tools/mirror.py` 镜像），**没有新增任何权限**——
  接口返回 `Access-Control-Allow-Origin: *`，所以 `host_permissions` 仍然由 `sync_whitelist.py` 管，
  一个字符都没动。
- 设置面板多了「Translation」一栏，扩展的弹窗和手机的设置页共用同一份实现；快捷键列表里多了 `y`。
- 解析器、文库存储、同步层都没有改动。
