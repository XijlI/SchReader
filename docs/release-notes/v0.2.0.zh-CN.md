## 0.2.0 新增

### 多设备同步

库、阅读位置、阅读历史、高亮，现在会在浏览器和手机之间保持一致。**设置 → Sync**，粘一串带
`gist` 权限的 GitHub token，点 Connect；第二台设备粘**同一个** token，它会自己找到同一个私有 gist。

- 只传元数据：题名、链接、标签、备注、阅读位置、高亮文字。正文和 PDF 永远不上传。
- 两台设备改的是不同内容就都保留：标签取并集，备注和进度取更新的那次。
- 一台删掉的论文另一台也会消失；但如果那台设备在上次同步之后又改过它，则以修改为准、论文保留。
- token 只存在这台设备本地。**Disconnect** 只让这台设备停止同步，gist 和其他设备不受影响。
- 改动后几秒自动推，打开库时自动拉（切回标签页也会拉一次）。

### 图标统一

浏览器图标和手机桌面图标现在是同一个字母、同一个比例，并且都由同一个源
（`tools/icon/make_mark.py`）生成：

- 字母换成 **Libre Caslon Text Bold**（SIL Open Font License）。
- 旧的 SVG 渲染管线把浏览器 PNG 画小了约 24% 还往左下偏了，现在改成满幅、居中直接绘制。
- 安卓自适应图标改成按"启动器实际显示的 72dp"来定尺寸，视觉重量和浏览器图标一致，不再偏胖 34%。
- 新增**单色图层**：Android 13+ 开了"主题图标"时，SchReader 不再是桌面上唯一一个彩色图标。

### 内部

- 库条目带上 `updatedAt`（合并排序用），同步文件里存一份"上次双方一致"的摘要，用来区分"删除"和
  "这台设备本来就没有"。
- 新增 `dev/sync-sim.mjs`：两台隔离设备打一个内存 gist，约 1 秒跑完，覆盖合并、冲突、删除、
  清空历史、以及"没变化时不写"。
- 库 / 阅读页 / 搜索 / 设置四个页面重新检查过运行时错误；App 与扩展共用同一套资源
  （`android/tools/mirror.py` 在构建时镜像）。
