**English** · [中文](#chinese)

SchReader turns any publisher's article page into a clean, Nature-like reading layout — one text
column with a fixed **Sections / Figures / References** rail — as a Chrome (MV3) extension and as an
Android app. Both hosts share one extractor, one reader page and one library store.

## Downloads

| File | What it is |
|---|---|
| `schreader-android-v0.2.0.apk` | Android app, Android 8.0+ (minSdk 26). Copy it to the phone and tap to install over 0.1.0. |
| `schreader-chrome-v0.2.0.zip` | Chrome / Edge extension (Manifest V3). Unzip, open `chrome://extensions`, turn on Developer mode, click "Load unpacked" and pick the unzipped folder. |
| `SHA256SUMS.txt` | SHA-256 checksums for both files. |

## What is new in 0.2.0

### Sync across devices

Your library, reading positions, reading history and highlights now follow you between the browser
and the phone. **Settings → Sync**, paste a GitHub token with the `gist` scope, press Connect; on the
second device paste the *same* token and it finds the same private gist by itself.

- Only metadata travels — titles, links, tags, notes, positions, highlight text. Never the article
  body, never a PDF.
- Two devices editing different things keep both: tags merge, note and position take the newer edit.
- A paper deleted on one device disappears from the other — unless you edited it on the other one
  after the last sync, in which case the edit wins and the paper stays.
- The token lives only on that device. **Disconnect** stops one device and leaves the gist and the
  other devices untouched.
- Pushes a few seconds after a change, pulls when you open the library (and when the tab comes back
  to the front).

### One icon everywhere

The browser icons and the phone's launcher icon are now the same mark at the same proportion, and
both are generated from one source (`tools/icon/make_mark.py`):

- The letterform is **Libre Caslon Text Bold** (SIL Open Font License) instead of Literata.
- The browser PNGs had been rendered ~24% too small and shifted down-left by the old SVG pipeline;
  they are now drawn full-bleed and centred.
- The Android adaptive icon is drawn for the 72 dp a launcher actually shows, so it reads at the same
  weight as the toolbar icon instead of 34% bolder.
- Added a **monochrome layer**: on Android 13+ with themed icons on, SchReader is no longer the one
  coloured icon on the home screen.

### Under the hood

- Library entries carry `updatedAt` (what the merge sorts on), and the sync file keeps a digest of
  the last agreed state so deletes are distinguishable from a fresh device.
- New `dev/sync-sim.mjs`: two isolated devices against an in-memory gist, ~1 s, asserts merge,
  conflict, delete, clear-history and "no writes when nothing changed".
- The library, reader, search and settings pages were re-checked for runtime errors, and the app is
  built from the same assets as the extension (`android/tools/mirror.py`).
