## 0.4.0 新增

### 收藏的词有了自己的生词本

阅读时选中文字，点「译」，再点译文卡片上的 **★**：词、译文和它所在的例句一起进文库的
**Words（生词本）** 标签（`Saved / History / Words`）。

- 这是生词本，不是文章笔记。文章原有的 note 一个字都不动；收藏一个词也不会再顺手把整篇论文塞进文库
  ——之前的「Save note」为了给一个词找个落脚点，会把整篇文章收藏掉。
- 每条都留着词出现的那句例句、出处论文（可点开）和时间。例句太长会在词尾截断加省略号，不会断在半个词上。
- 词、译文、例句、出处都能搜；**Copy** 复制成「词 ⇥ 译文」两列（粘进 Excel 或 Anki 导入正好两栏）；
  Delete 删掉这一条。
- 同一篇文章里同一个词存两次 = 更新那一条，不会重复；换一篇文章存同一个词，是另一条（例句不同）。
- 生词本和文库走同一个私有 gist 同步：手机上存的词在 Chrome 里能看到，反过来也一样，删除同样会传播。
  没连过同步的设备，就只存在本机。

### 参考文献：区间、被引次数和表格

- 出版社把区间（`20–23`）渲染成两个链接时，中间的数字根本没有自己的元素，21、22 就被判成「正文未引用」、
  也点不过去——一篇 PNAS 的 43 条文献里有 4 条是这种情况。现在区间里每个数字都是独立的小标签；
  文献表里没有对应条目的数字仍是普通文字，图表区间（"Figs. 5–7"）不受影响。
- `↑ 被引 3 次` 又有了自己的一行：点它直接跳到正文里的引用处，再点一次走到下一次
  （「Citation 2 of 3」）。以前这一下只会闪一下文献条目、页面不动；现在跨屏的大跳转是瞬时到位，
  不再把整篇文章从眼前刷过去。
- Frontiers 这类（JATS）页面不再凭空多出图表：标签正则把 "Figure 2View in article" 的 "V" 当成了
  分图字母，于是四张图的论文侧栏列出八张；同样的毛病在 Wiley 上把 "Figure 1Open in figure viewer"
  变成了 "Figure 1O"。
- `<sup>` 的指数不再被当成引用（"1.41 × 10⁶ cells/mL" 以前会链接到文献 6）；表格单元格里的引用也会被
  链接，只在表格里被引的文献不再显示「正文未引用」；表格也恢复成表格，不再挤成一整段。
- 页脚清理能穿过只放推广链接的外壳了，"the authors declare …" 也不再被当成页脚删掉——它下面才是真正的
  利益冲突与资助说明。

### 底层

- `extension/library-store.js` 新增存储键 `sr-words`（`words` / `addWord` / `patchWord` /
  `removeWord`），Android 原生存储（`Library.kt`）同步加了这一项，gist 合并也带上 `words` 段：
  三方合并照旧，删除能传播；条目 id 由「词 + 论文」算出来，两台设备算出的 id 一致，重复收藏就是原地更新。
- `dev/sync-sim.mjs` 用两台互相隔离的设备把生词本跑了一遍：保存、同步、原地刷新、删除，以及一次
  「什么都没变就不写 gist」的空同步。
- 没有新增页面、没有新增权限：生词本就长在已经被 `android/tools/mirror.py` 镜像进 APK 的那几个页面里。
