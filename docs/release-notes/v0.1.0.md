**English** · [中文](#chinese)

SchReader turns any publisher's article page into a clean, Nature-like reading layout — one text
column with a fixed **Sections / Figures / References** rail — as a Chrome (MV3) extension and as an
Android app. Both hosts share one extractor and one reader page; they differ only in how they get the
page HTML.

## Downloads

| File | What it is |
|---|---|
| `schreader-android-v0.1.0.apk` | Android app, Android 8.0+ (minSdk 26). Copy it to the phone and tap to install. |
| `schreader-chrome-v0.1.0.zip` | Chrome / Edge extension (Manifest V3). Unzip, open `chrome://extensions`, turn on Developer mode, click "Load unpacked" and pick the unzipped folder. |
| `SHA256SUMS.txt` | SHA-256 checksums for both files. |

## What is in it

**Reader**
- Single text column with a fixed rail for sections, figures and references; hovering an inline
  citation shows the reference without leaving the paragraph.
- Figure lightbox, keyboard shortcuts (`j`/`k`, `s`/`f`/`r`, `z`, `t`, `Esc`), per-article typography.
- 17 reading themes plus a custom palette mixer that derives every shade from two colours.

**Library**
- Stores metadata only — title, authors, journal, year, DOI, link, your tags and note, reading
  position. No article text and no PDFs, so the reader still runs inside your own login session.
- Search, tags, notes, reading history, and export/import as BibTeX, RIS, CSV or JSON.

**Search shelf**
- Google Scholar plus a shelf of publisher home pages; add your own and they appear on the phone too.

**Extension**
- The toolbar icon opens the library; a floating pill converts the tab you are on into the reader.
- Settings panel for theme, typeface, size and the sites the extension may run on.

**Android app**
- Opens on **My library** with a bottom bar: Library / Search / Settings, in the same theme as the page.
- Browser tabs (up to 8, restored after a restart); tapping the section you came from returns to the
  page you left — including back into the reader at the same scroll position.
- Page zoom 25–200%, share sheet, and `schreader://` deep links.

## Notes

- The package id is `com.schreader.app`, so this build installs alongside any pre-rename copy.
- The library starts empty: storage keys were renamed with the project, so older entries are not read.
- Full text is re-parsed from the page each time — nothing is archived, and PDFs are not rendered.
